# Launcher (灵动岛) 接口

### 列表过滤
- **URL**: `/api/launcher/filter`
- **Method**: `POST`
- **说明**: 通过外部服务过滤列表项数据。

### Launcher 动作执行
- **URL**: `/api/launcher/action`
- **Method**: `POST`
- **说明**: 外部请求激活 Launcher 并传入指定的动作执行请求。

### 激活 Inspector
- **URL**: `/api/inspector/activate`
- **Method**: `POST`
- **说明**: 激活 TaiChi 内置的窗口或视图审查器 (Inspector)。
